# MarocTv2.0

Base Android Kotlin + Jetpack Compose conçue pour téléphone Android et Android TV.

## Générer un APK
1. Ouvrir le dépôt GitHub.
2. Aller dans **Actions**.
3. Choisir **Construire MarocTv2.0 APK**.
4. Cliquer sur **Run workflow** (ou pousser un commit sur `main`).
5. À la fin, télécharger l'artefact `MarocTv2.0-debug`.

## État actuel
Cette base fournit l'application de démarrage, une navigation simple, une recherche locale et des favoris en mémoire. Les fonctions de lecture vidéo, playlists M3U, catalogues distants, profils, synchronisation et sous-titres restent à développer.

N'ajouter que des flux et catalogues que vous êtes autorisé à utiliser.
